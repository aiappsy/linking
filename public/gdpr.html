GDPR & Datasikkerhet

Full Compliance with EU Regulation 2016/679 and Norwegian Personopplysningsloven Full overholdelse av personvernforordningen (GDPR) og norsk personopplysningslov

Strict Privacy Commitment: We design and engineer all applications according to the principles of Data Protection by Design and by Default. We ensure your corporate and customer data remains strictly confidential and is never used to train public AI foundation models.

1. Zero AI Model Training Guarantee

When you use AIAPPSY platforms or commission bespoke action agents:

  • No Public Model Training: Your business records, financial accounting syncs, prompts, and customer data are never used to train or fine-tune public foundation models (Claude, Gemini, GPT).
  • Ephemeral Context Execution: Autonomous agent browser runs and API transactions operate in isolated memory contexts that are cleared upon task completion.

2. Architectural Isolation (Tenant Separation)

Enterprise data security is enforced at the infrastructure level:

  • Cloud Run Container Isolation: Microservices run in independently isolated container instances hosted on Google Cloud Run.
  • AES-256 Encryption: In-transit data is protected with TLS 1.3 encryption, and at-rest data is safeguarded with AES-256 standards.
  • Sub-Processor Security: We partner exclusively with tier-1 enterprise cloud providers adhering to SOC 2 Type II, ISO 27001, and EU Standard Contractual Clauses (SCCs).

3. Data Processing Agreements (DPA)

For bespoke enterprise contracts and whitelabel licensing partnerships, AIAPPSY provides standardized or custom Data Processing Agreements (DPA) specifying exact sub-processor roles, breach notification protocols, and data return/destruction obligations upon contract completion.

4. Data Subject Requests

We provide full support for customer data rights:

  • Right of access, rectification, portability, and complete erasure within 30 days of written request.
  • Direct contact: paljuritzen@gmail.com.

Kompromissløst personvern: Alle våre løsninger bygges etter prinsippene om innebygd personvern (Privacy by Design). Vi garanterer at din bedrifts interne data aldri benyttes til å trene åpne AI-modeller.

1. Ingen AI-modelltrening på dine data

Når din virksomhet tar i bruk AIAPPSYs apper eller bestiller skreddersøm:

  • Null modelltrening: Bedriftens data, fakturaopplysninger fra Fiken/Tripletex og kundehenvendelser blir aldri brukt til å trene offentlige språkmodeller (Claude, Gemini, ChatGPT).
  • Isolerte kjøremiljøer: Autonome handlingsagenter opererer i lukkede minneprosesser som nullstilles så snart oppgaven er fullført.

2. Teknisk og organisatorisk sikkerhet

Sikkerheten er ivaretatt på infrastrukturnivå:

  • Isolerte Cloud Run containere: Tjenestene kjører i lukkede mikrotjenester hos Google Cloud Run med strenge tilgangskontroller.
  • Kryptering: All datatrafikk er kryptert under transport (TLS 1.3) og under lagring (AES-256).
  • Europeiske garantier: Vi benytter kun skyleverandører som oppfyller EUs krav til standardavtaler (SCC) og GDPR-etterlevelse.

3. Databehandleravtale (DPA)

For bedriftskunder og white-label partnere tilbyr vi standardisert eller tilpasset databehandleravtale (DPA) i henhold til Datatilsynets retningslinjer, som regulerer ansvarsforhold, varsling ved eventuelle avvik og sletterutiner.

4. Henvendelser og sletting

Ved forespørsel om innsyn, dataportabilitet eller full sletting av opplysninger i henhold til GDPR artikkel 17, ta kontakt på paljuritzen@gmail.com.
