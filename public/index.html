⚡Raskeste metode i Namecheap (Fungerer umiddelbart uten egen GCP-konto):

I stedet for CNAME til ghs.googlehosted.com (som krever Cloud Run-godkjenning i Google Cloud Console), kan du sette opp URL Redirect direkte i Namecheap. Da håndterer Namecheap SSL-sertifikatet automatisk:

Type: URL Redirect Record
Host: @ (for aiappsy.com) eller go (for go.aiappsy.com)
Value / Destination URL: https://ais-pre-53feievmlb7bxf43a2muqn-92119917321.asia-east1.run.app/
Redirect Type: Permanent (301) eller Unmasked
⚠️ Viktig for toppdomener (Apex) uten subdomene:

Et apex-domene som aiappsy.com kan ikke ha en CNAME på @. Legg inn disse 4 A-postene hos Namecheap / domeneregistrator:

Type: A | Host: @ | Verdi: 216.239.32.21
Type: A | Host: @ | Verdi: 216.239.34.21
Type: A | Host: @ | Verdi: 216.239.36.21

⚙️ HTTP 302 Omdirigeringsmotor

Hver innkommende forespørsel mot /:slug matches umiddelbart mot JSON-databasen. Dersom matchen eksisterer, returneres en HTTP 302 Found redirect direkte til mål-URL-en uten unødvendig forsinkelse, samtidig som klikktelleren inkrementeres asynkront.
