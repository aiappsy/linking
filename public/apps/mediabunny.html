Frequently Asked Questions

Ofte stilte spørsmål om MediaBunny

Why is on-device WebAssembly (WASM) media processing superior? Hvorfor er lokal WebAssembly (WASM) mediekonvertering overlegen? +

By executing FFmpeg and media codecs directly in the user's browser via WebAssembly, files never upload to third-party cloud servers. This eliminates bandwidth bottlenecks, ensures strict GDPR data privacy, and cuts server rendering costs to zero.

Ved å kjøre FFmpeg og medieprosessering direkte i nettleseren via WebAssembly, lastes filene aldri opp til eksterne servere. Dette gir lynrask prosessering uten ventetid, 100 % GDPR-personvern og null serverkostnader.

What is EBU R128 audio normalization? Hva innebærer EBU R128 lydnormalisering? +

EBU R128 is the international broadcasting standard for perceived loudness. MediaBunny automatically normalizes podcast and video audio tracks to exactly -23 LUFS / -14 LUFS for YouTube, Spotify, and TikTok compliance.

EBU R128 er den internasjonale kringkastingsstandarden for oppfattet lydstyrke. MediaBunny normaliserer podkaster og lydspor automatisk til nøyaktig -23 LUFS / -14 LUFS tilpasset YouTube, Spotify og TikTok.

How much file size reduction does smart CRF video compression achieve? Hvor mye kan filstørrelsen reduseres med smart CRF-videokomprimering? +

MediaBunny typically slashes MP4/WebM video file sizes by 60% to 80% with visually lossless Constant Rate Factor (CRF) encoding, perfect for web delivery and email attachments.

MediaBunny reduserer normalt filstørrelsen på MP4- og WebM-videoer med 60 % til 80 % uten synlig kvalitetstap, optimalt for rask weblast og e-postvedlegg.

Can MediaBunny operate without an internet connection? Kan MediaBunny brukes uten internettforbindelse? +

Yes. Once the initial Progressive Web App (PWA) assets are cached, all media conversion and audio filtering run 100% offline on the user's local CPU/GPU.

Ja. Så snart PWA-komponentene er bufret i nettleseren, foregår all konvertering og redigering 100 % lokalt på brukerens egen enhet uten nettilgang.
